# GEMINI SESSION START — DIGITAL LIBRARY

Sebelum melakukan coding, ikuti langkah berikut.

## STEP 1 — VERIFY WORKSPACE

Periksa workspace secara rekursif.

Saya membutuhkan project lengkap, bukan hanya beberapa file.

Minimal verifikasi keberadaan:
- app.py
- database_setup.py
- templates/
- static/
- requirements.txt
- database yang digunakan

Jika workspace tidak lengkap, JANGAN coding.

Output tepat:
WORKSPACE INCOMPLETE — PROJECT SOURCE BELUM TERSEDIA SEPENUHNYA.

Lalu tampilkan file/folder yang terlihat dan apa yang kurang.

## STEP 2 — READ PROJECT CONTEXT

Baca:
- PROJECT_CONTEXT.md
- PROJECT_RULES.md

Kemudian cocokkan dengan file aktual.

## STEP 3 — AUDIT READ-ONLY

Untuk sesi audit pertama:
- jangan mengubah file
- jangan membuat file
- jangan menghapus file
- jangan memindahkan file
- jangan mengubah database
- jangan menambah dependency

Buat laporan:
1. struktur project
2. backend
3. database
4. template inheritance
5. frontend stack
6. fitur existing
7. konflik/risiko
8. file yang harus dilindungi
9. rekomendasi urutan pekerjaan

## STEP 4 — NO ASSUMPTIONS

Jika menemukan sesuatu yang tidak jelas:
jelaskan ketidakpastiannya.

Jangan mengarang.

## STEP 5 — FINAL AUDIT OUTPUT

Gunakan struktur:

PROJECT STATUS:
ARCHITECTURE:
DATABASE:
FRONTEND:
EXISTING FEATURES:
ARCHITECTURAL RISKS:
SECURITY NOTES:
FILES TO PROTECT:
RECOMMENDED NEXT STEP:

Jangan melakukan implementasi pada audit pertama.
