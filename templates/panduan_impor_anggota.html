Jaminan Keamanan & Perlindungan Privasi (DEC-023)

Mengunduh file template atau membaca panduan ini sama sekali tidak menulis atau mengubah database sistem perpustakaan (Zero-Write). Sesuai ketetapan arsitektur DEC-023, sistem perpustakaan tidak menyimpan nomor telepon maupun kelas siswa. Jika file spreadsheet dari Tata Usaha memuat kolom tersebut, sistem akan mengabaikannya secara otomatis dan menampilkan peringatan ramah tanpa membocorkan data pribadi.

1 Struktur Kolom Template Resmi

File CSV wajib memiliki baris header pada baris pertama dengan 5 nama kolom standar berikut:

Nama Kolom Sifat Pilihan / Format Penjelasan & Contoh Pengisian
nama Wajib Teks bebas (maks. 150 karakter) Nama lengkap anggota sekolah. Contoh: Ahmad Fauzi, Budi Santoso, S.T..
jenis Wajib murid
guru_jurusan
guru_umum
staf
teknisi 		Peran/kategori anggota di sekolah:
  • murid: Siswa aktif sekolah.
  • guru_jurusan: Guru kejuruan / program keahlian.
  • guru_umum: Guru mata pelajaran umum.
  • staf: Tenaga kependidikan / tata usaha.
  • teknisi: Laboran lab / teknisi bengkel.
keterangan Opsional Teks bebas (maks. 255 karakter) Rincian pelengkap spesifik per peran:
  • Untuk murid: nama Jurusan (misal: Teknik Komputer dan Jaringan).
  • Untuk guru kejuruan: nama Program Keahlian.
  • Untuk guru umum: Mata Pelajaran (misal: Matematika).
  • Untuk staf/teknisi: nama Bagian Tugas / Laboratorium.
status Opsional aktif atau nonaktif Status operasional akun anggota. Jika dikosongkan, sistem otomatis menetapkan status aktif.
id_anggota Opsional Format Crockford Base32: M-XXXXXX Kosongkan untuk mendaftarkan anggota baru (sistem otomatis membuatkan ID acak unik). Isi dengan ID anggota yang sudah ada jika ingin memperbarui data anggota lama.
2 Penanganan Kolom Kelas dan Nomor Telepon (DEC-023)

Sekolah sering kali memiliki file ekspor dari sistem Tata Usaha yang memuat kolom rombongan belajar (kelas) dan kontak telepon. Berikut aturan penanganannya:

Data yang Dilarang Disimpan (DEC-023):
  • Nomor Telepon / HP / WhatsApp: Melindungi privasi siswa dan guru, serta menghindari pemeliharaan nomor ganti.
  • Kelas / Rombel Spesifik (misal: XII RPL 1): Menghindari kewajiban pembaruan massal tiap pergantian tahun ajaran. Siswa cukup diidentifikasi dari Jurusannya pada kolom keterangan.
Perilaku Sistem Jika Kolom Ditemukan:
  • Sistem tidak akan menolak file hanya karena ada kolom kelas atau telepon.
  • Kolom tersebut akan diabaikan secara otomatis.
  • Sistem memunculkan peringatan ramah bahwa kolom diabaikan.
  • Nilai isi kolom tidak pernah disimpan, tidak dimasukkan ke kolom lain, dan tidak dicatat ke log.
