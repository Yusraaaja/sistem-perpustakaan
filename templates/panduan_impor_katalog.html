1 Kapan Sebaiknya Menggunakan Fitur Impor Massal?

Fitur impor spreadsheet CSV dirancang khusus untuk mempermudah petugas perpustakaan ketika harus memasukkan banyak data buku sekaligus:

Gunakan Impor Spreadsheet CSV Jika:
  • Pengadaan buku baru dalam jumlah puluhan hingga ratusan judul.
  • Penerimaan hibah atau sumbangan koleksi buku tahun ajaran baru.
  • Digitalisasi atau migrasi data perpustakaan dari sistem lama.
Gunakan Form Tambah Buku Manual Jika:
  • Hanya menambahkan 1 atau 2 judul buku baru.
  • Memerlukan deteksi langsung peringatan judul mirip di layar.
  • Ingin langsung mencetak label barcode per eksemplar seketika.

kategori Wajib Teks, maks 100 karakter Klasifikasi koleksi buku. Contoh: Fiksi, Buku Pelajaran, Referensi, Sains, Agama, Sejarah, atau Ensiklopedia.
jumlah Wajib Bilangan bulat ≥ 1 (Maks 1.000) Jumlah eksemplar fisik buku yang tersedia di perpustakaan. Harus berupa angka bulat positif (misal: 1, 5, 10). Dilarang mengisi angka 0, bilangan negatif, atau bilangan pecahan/desimal.
Konsep Eksemplar Fisik (DEC-004 & DEC-013)

Perpustakaan digital ini membedakan antara Judul Katalog dengan Eksemplar Fisik:

  • Satu baris dengan jumlah = 5 berarti sistem akan membuat 1 judul buku dan secara otomatis mencetak 5 eksemplar fisik terpisah (masing-masing memiliki ID eksemplar unik untuk ditempeli stiker barcode).
  • Jangan menduplikasi baris: Jika perpustakaan memiliki 10 buah buku "Matematika Kelas 10", Anda cukup menuliskan 1 baris saja dengan nilai kolom jumlah = 10. Jangan membuat 10 baris terpisah dengan judul yang sama.
Hapus Data Contoh Sebelum Digunakan!

Template unduhan menyertakan beberapa baris data contoh yang berlabel (Contoh) untuk memberikan gambaran format yang benar:

  • Wajib Hapus Baris Contoh: Sebelum Anda mengisi data buku perpustakaan yang sebenarnya, pastikan Anda menghapus seluruh baris data contoh tersebut.
  • Pertahankan Header: Pastikan baris paling atas (baris 1 yang berisi nama kolom judul,penulis,isbn,kategori,jumlah) tetap utuh dan tidak terhapus.
  • Periksa Ulang: Cek kembali judul, penulis, ISBN, kategori, dan jumlah sebelum file digunakan untuk menghindari kesalahan input.
3 Petunjuk Membuka & Menyimpan di Aplikasi Spreadsheet

File CSV (Comma Separated Values) dapat dibuka menggunakan berbagai aplikasi pengolah spreadsheet populer:

Microsoft Excel
  1. Buka Excel, pilih menu Data > From Text/CSV (atau klik dua kali file).
  2. Pastikan Delimiter dipilih Comma (Koma) dan File Origin UTF-8.
  3. Isi data buku perpustakaan.
  4. Saat menyimpan, pilih menu File > Save As dan pilih format CSV UTF-8 (Comma delimited) (*.csv).
Google Sheets
  1. Buka Google Sheets di browser.
  2. Pilih menu File > Import > Upload, lalu pilih template CSV yang telah diunduh.
  3. Edit data bersama tim secara daring.
  4. Saat selesai, unduh kembali melalui menu File > Download > Comma Separated Values (.csv).
LibreOffice Calc
  1. Buka file dengan LibreOffice Calc.
  2. Pada jendela Text Import, pilih Character set: Unicode (UTF-8) dan centang Separator: Comma.
  3. Edit dan lengkapi data buku.
  4. Simpan kembali dengan format Text CSV (.csv).

Catatan Validasi Server pada Tahap Impor Berikutnya

Mengikuti format template adalah syarat awal penyusunan data. Namun, server perpustakaan akan tetap melakukan validasi ketat terhadap setiap baris saat proses impor dilakukan pada tahap berikutnya:

  • Judul, penulis, dan kategori yang kosong atau melebihi batas karakter akan ditandai sebagai error.
  • ISBN yang tidak sah (bukan 10 atau 13 digit angka) akan ditolak.
  • Nilai jumlah yang bernilai 0, negatif, desimal, atau bukan angka akan ditolak.
  • Potensi judul mirip atau duplikasi ISBN akan terdeteksi di tahap pratinjau impor (Task 3-06) sebelum Anda mengonfirmasi penyimpanan massal (Task 3-07).
